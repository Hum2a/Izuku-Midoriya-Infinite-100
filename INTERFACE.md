# Web modding (schema 1)

- **`deku-infinite100.css`** — `https://*/*` + `http://*/*`: green + Eri gold mist, links, scrollbars, `::selection`, placeholders; `:root` tokens for Opera/GX env vars.
- **`sites-01` … `sites-06`** — Per-host tweaks (`manifest.json` → `page_styles`).
- **`deku-infinite-opera.css`** — `https://*.opera.com/*`

Shaders, sounds, and wallpaper are separate from `page_styles`.
